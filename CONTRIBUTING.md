# Contributing to Sundial

Short and to the point.

This repo is Sundial's front page. The server is [SundialServer](https://github.com/HumanGenome/SundialServer), and that is where code and server problems go.

## Reporting bugs

Open an issue on [SundialServer](https://github.com/HumanGenome/SundialServer/issues). Include:

- The SundialServer version and the Solarpunk build
- Steps to reproduce
- The server's logs

If your issue is about a hosted server you rent (panel, billing, support), contact your host directly.

The Sundial app is retired. Its last release, 0.1.72, puts Solarpunk's own settings back; there will be no further releases. Players do not need it on Solarpunk 1.3.0.

## Pull requests

Pull requests go to [SundialServer](https://github.com/HumanGenome/SundialServer); its CONTRIBUTING.md has the details.

## Code of conduct

Be civil. Be technical. Don't post game-piracy or anti-cheat-evasion material in issues or PRs.
